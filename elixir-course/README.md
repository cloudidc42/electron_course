## เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ถูกออกแบบมาเพื่อพาคุณจากผู้เริ่มต้นที่ไม่รู้จัก Elixir เลย ไปสู่ระดับมืออาชีพที่สามารถสร้างระบบขนาดใหญ่ รองรับผู้ใช้งานหลายล้านคน และทำงานได้ 24/7 โดยไม่มีวันล่ม

### ทำไมต้องเรียน Elixir?

- **Discord** ใช้ Elixir รองรับผู้ใช้งานกว่า 100 ล้านคน
- **WhatsApp** สร้างด้วย Erlang/BEAM (base ของ Elixir) รองรับข้อความกว่า 50 พันล้านข้อความต่อวัน
- **Pinterest** ใช้ Elixir ลดการใช้ Server จาก 450 เหลือ 150 เครื่อง
- **Bleacher Report** ลด Server จาก 150 เหลือ 5 เครื่องด้วย Elixir

## วิธีใช้หลักสูตรนี้

1. **อ่านตามลำดับ** - เนื้อหาถูกออกแบบให้เรียนต่อกันได้
2. **ลงมือทำทุก code** - อย่าแค่อ่าน ให้พิมพ์โค้ดเองทุกครั้ง
3. **ทำแบบฝึกหัด** - ทุก part มีแบบฝึกหัดให้ทำ
4. **สร้าง Project จริง** - นำความรู้ไปสร้างโปรเจกต์จริงของตัวเอง

## ความต้องการของผู้เรียน

- มีพื้นฐานการเขียนโปรแกรมมาบ้าง (ภาษาอะไรก็ได้)
- มีคอมพิวเตอร์ที่ติดตั้ง Elixir ได้
- มีความมุ่งมั่นในการเรียนรู้

## การติดตั้ง (Quick Start)

```bash
# macOS
brew install elixir

# Ubuntu/Debian
apt-get install elixir

# Windows
# ดาวน์โหลดจาก https://elixir-lang.org/install.html

# ตรวจสอบการติดตั้ง
elixir --version
```
